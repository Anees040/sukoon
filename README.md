# Sukoon (سکون)

**Namaz times · auto-silent at prayer times · namaz & qaza tracker · qibla — offline, private, no ads.**

An Android-only Flutter app for Pakistani Muslims, fully localized in English + Urdu.

## Modules

| # | Module | What it does |
|---|--------|--------------|
| 1 | Auto-silent | Phone goes to DND (alarms-only) at each prayer time, ringer restores after 15/20/30 min. One-tap **Masjid Mode**. Survives reboot; works with the app killed. |
| 2 | Prayer times | Offline calculation (adhan package, Karachi method + Hanafi Asr defaults), ~100 Pakistani cities browser. |
| 3 | Namaz tracker | Daily check-off (prayed / jama'at / missed), streaks, monthly heatmap, Period mode. |
| 4 | Qaza-e-umri | Guided estimate wizard (bulugh-based, Sunni-Hanafi defaults, fully editable), repayment planner, achievements. |
| 5 | Qibla | Sensor compass + static bearing fallback. |
| 6 | i18n | Every string in English + Urdu (RTL). |

## Architecture (one paragraph)

Dart owns UI, prayer math, and history (sqflite). **Native Kotlin owns everything that must run while the app is dead**: `AlarmManager` exact alarms fire pure-Kotlin receivers that flip Do-Not-Disturb on/off by saving and restoring the user's interruption filter. Dart pushes a 7-day schedule of prayer instants (plus pre-localized notification strings) through `MethodChannel sukoon/alarms` into native `SharedPreferences ("sukoon_state")`; boot/timezone receivers reschedule from that same store. No foreground services, no polling, no network — anywhere.

## Size budget

Target 12–18 MB Play download, hard cap 25 MB. No bundled media, no Lottie, code-driven animations only, one optional Urdu font. Check with `flutter build appbundle --release --analyze-size`.

## Fiqh stance (important)

The qaza calculator produces **estimates** using documented, mainstream Sunni (Hanafi-default) rules; every number is user-editable and every result screen says to confirm with a local scholar. The app deliberately contains **no Quran or Hadith text** — see `docs/skills/fiqh_copy_rules.md`.
